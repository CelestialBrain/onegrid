# API surface reports

This directory holds one `<package>.api.md` file per published oneGrid
package. Each report is a snapshot of that package's TypeScript public
surface — every `@public` and `@beta` export, with its full signature —
generated by [api-extractor](https://api-extractor.com/) walking the
built `dist/**/*.d.ts` files.

These files exist so a pull request that touches the surface lights up
as a diff here. The `pnpm api:check` CI gate fails when a PR ships a
surface change without updating the corresponding report.

## Regenerating

After changing a public export, run from the repo root:

```sh
pnpm build           # produces the dist/*.d.ts api-extractor reads
pnpm api:extract     # regenerates every <package>.api.md
```

Commit the diff to `docs/api/*.api.md` alongside the source change.

## CI gate

```sh
pnpm api:check       # exits non-zero when a report is stale
```

CI runs this after `pnpm build` and surfaces the diff in the PR.

## What's covered

The generator walks every workspace package whose `package.json` is
scoped `@onegrid/*` (plus the `onegrid` meta package) and that has a
built `dist/index.d.ts`. Per-package `api-extractor.json` configs are
auto-written by `scripts/generate-api-reports.mjs`; do not edit them
by hand — regenerate instead.

Per-package stability tagging (the `@public` / `@beta` tags that
api-extractor reads) is enforced separately by `pnpm surface:check`,
which fails when a top-level export in `src/index.ts` ships untagged.
See [SURFACE.md](../SURFACE.md) for the tier policy.
