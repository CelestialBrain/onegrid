**Repo**: https://github.com/revolist/revogrid
**License**: MIT (core). RevoGrid Pro is a separate commercial offering at https://rv-grid.com/pro/.
**Pricing**: Core MIT-free. Pro pricing not publicly listed; "contact sales".
**Latest version**: v4.21.7 (released 2026-05-03, per GitHub releases)
**Stars**: ~3.4k
**Maintenance**: Active. Single-maintainer-led (revolist) but ships frequent patch releases via a GitHub Actions CD pipeline that publishes to multiple framework wrapper packages on every change.

## Architecture

Built as a **Web Component using StencilJS**. The single `<revo-grid>` custom element is the source of truth; the React, Vue 2/3, Angular, and Svelte packages are thin Stencil-generated wrappers around the same compiled web component output. This is the project's central architectural bet — write once, ship a typed wrapper to every framework automatically through Stencil's output targets.

Rendering uses what the project calls an "intelligent Virtual DOM" with **smart row recombination** — instead of unmounting/remounting DOM nodes on every scroll tick, RevoGrid recycles row elements and rebinds data, minimizing redraws. Both rows and columns are virtualized, supporting "millions of cells in the viewport".

State is held inside the component (Stencil's reactive `@State` / store pattern), with imperative public methods and a rich event API exposed for external coordination. Data and column changes through props trigger reactive re-renders; deep mutations require using the provided source/range APIs rather than mutating arrays in place.

Plugin system is first-class — plugins receive access to internal grid providers (data provider, dimension provider, viewport provider, selection provider) and can hook into the lifecycle to add or override behavior without forking. Built-in features (sorting, filtering, grouping, export, autofill, clipboard) are themselves implemented as plugins.

Framework coupling: zero. Because it's a Web Component, embedding RevoGrid in any framework — including frameworks that don't have a wrapper — is just dropping the custom element into the DOM and setting properties.

## Framework support

- **Vanilla JS / Web Component**: native (`@revolist/revogrid`)
- **React**: native wrapper (`@revolist/react-datagrid`)
- **Vue 3**: native wrapper (`@revolist/vue3-datagrid`)
- **Vue 2**: native wrapper (`@revolist/vue-datagrid`)
- **Angular**: native wrapper (`@revolist/angular-datagrid`)
- **Svelte**: native wrapper (`@revolist/svelte-datagrid`)
- **Solid / Qwik / others**: works via the underlying Web Component, no first-party wrapper

All wrappers are auto-generated by Stencil's framework output targets and ship matching TypeScript types from the same source.

## Features (be EXHAUSTIVE)

### Sorting
Single and multi-column sorting, customizable per-column comparator, programmatic sort API. Sort events are observable; sort logic can be replaced via `cellCompare` overrides.

### Filtering
Built-in column filters with text, number, and select operators. Custom filter operations supported. Pro tier adds advanced filter UIs and filter sets.

### Grouping
Hierarchical/grouped row representation supported in core. Group expand/collapse via UI and API.

### Pivoting
Not in core. Pro tier markets "advanced data-management patterns" but no full pivot UI is documented at the level of Perspective or AG Grid.

### Aggregations
Not in core. Listed as a Pro-tier feature.

### Editing
Per-cell editing with default editors (text, select, date) plus full custom editor templates. JSX/TSX templating supported in the editor slot. Validation hooks via `beforeEdit` events.

### Selection
Cell focus, range selection (Excel-style), multi-range, full row select. Keyboard navigation built in.

### Clipboard / copy-paste
Copy/paste compatible with Excel and Google Sheets — multi-cell paste preserves shape, type coercion handled per column.

### Virtualization
Both row and column virtualization (the project markets "virtual rows and columns"). Smart recombination recycles DOM nodes during scroll. Marketed at 60fps with claim of "3x less memory" than competing virtual grids; benchmarks repo at github.com/revolist/revogrid-benchmarks.

### Accessibility
WAI-ARIA roles applied. Keyboard navigation. Project advertises WCAG-compliance focus. Issue tracker shows accessibility is a recurring concern (e.g. #377 — text not selectable on readonly grids).

### Server-side row model / lazy loading
Supported via the data source plugin and trimmed-rows API for chunked loads, but not as a polished, configuration-driven server row model the way AG Grid Enterprise has. Effectively a manual integration.

### Streaming / live updates
Real-time updates supported by mutating the data source; smart recombination re-renders only affected cells. No formal pub/sub or batched-streaming primitive like Perspective's `update()`.

### Formulas / computed cells
Not in core. Pro markets "advanced formulas".

### Theming / custom cell renderers
Theme manager with multiple bundled themes. Custom cell, header, row, and column templates via JSX/TSX. CSS variable surface for color/sizing.

### Export
CSV and Excel-compatible export. Built-in export plugin.

### Master / detail
Not first-class. Achievable via custom row templates and external state, but no built-in detail-panel API.

### Tree data
Hierarchical/grouped representation supported in core. Tree-shaped data via grouping mechanism.

### Charts integration
None first-party.

### i18n / RTL
Localization supported. **Comprehensive RTL** support for Arabic, Hebrew, Persian, etc. Marketed explicitly.

### Mobile / touch
Touch interactions supported (touch range selection, scrolling). No dedicated mobile-optimized UI mode; uses the same DOM as desktop.

### Other notable features
- Drag-and-drop for rows and columns
- Pinned/frozen rows and columns (top, bottom, left, right)
- Server-side rendering compatible (Stencil pre-renders)
- Plugin system with full provider access (the most extensible point of the architecture)
- TypeScript types ship from the Stencil component, identical across all framework wrappers

## API style

Hybrid declarative + imperative. The dominant pattern is declarative: pass `source`, `columns`, and config props to `<revo-grid>` and listen for events. Imperative escape hatches available through `revogridElement.getSource()`, `getVisibleSource()`, `setDataObjectsByType()`, etc., which is necessary for streaming or paging scenarios.

TypeScript: first-class. Types come straight from Stencil's component definition.

Headless vs batteries-included: **batteries-included**. Renders a fully styled grid out of the box. Not a headless library — there's no "bring your own DOM" mode.

## Bundle size

Core `@revolist/revogrid` is a Stencil-compiled bundle. Public stats not published on the docs; npm and bundlephobia indicate ~150–200kB minified for the full grid + lazy-loaded plugin chunks (Stencil splits per component). Tree-shakeable at the framework-wrapper level — only the components you import ship.

## Performance claims (with sources)

- "60fps, 3x less memory" — homepage marketing claim (https://rv-grid.com/).
- Public benchmarks repo: https://github.com/revolist/revogrid-benchmarks compares against Handsontable, AG Grid, and others on virtual scrolling and large data ingestion.
- Marketed handling of "millions of cells" out of the box.

## Recurring weaknesses (GitHub issues, Reddit)

- **Text not selectable** in read-only / non-focusable grids — issue #377; awkward UX for copy-without-edit workflows.
- **Column drag-and-drop** glitches — column model not always in sync after reorder (issue #99).
- **Auto-sizing** based on content can break with more complex columns; visible scrollbar flash on the right (issue #600).
- **Pinned-row custom heights** unsupported (issue #284).
- **Documentation gaps** acknowledged by maintainer (issue #193 — "RevoGrid Documentation Enhancement"). Compared to AG Grid or MUI X, the docs are thinner and harder to navigate, especially around plugin authoring.
- **Single-maintainer risk** — bus factor of effectively 1; release velocity good but feature breadth depends on one person.
- **Pro is opaque** — RevoGrid Pro is a paid layer where many "enterprise" features (advanced filtering, formulas, aggregations) live; pricing isn't public, which slows enterprise adoption decisions.
- No first-party charts, master/detail, or pivot UI in the open-source tier.
